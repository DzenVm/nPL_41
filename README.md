# Frebamee — atlas strategii

Польськомовний сайт на Next.js 16: опис концепції стратегії та дві демонстрації
(симуляція погодних умов і розподіл ресурсів). Повна гра не реалізована.

## Домен і контакти

Канонічний домен: `https://frebamee.biz`.
Контакт: `kontakt@frebamee.biz` (адреса погоджена власником; скринька налаштовується окремо).
Обидва значення задані у `src/lib/site.ts`. Домен використовується для canonical,
OpenGraph, JSON-LD, sitemap і robots.txt. Змінна `NEXT_PUBLIC_SITE_URL` більше не потрібна.
Прив’язка домену в хостингу, DNS та пошта налаштовуються окремо від коду.

## Запуск

```sh
npm ci
npm run dev
```

## Перевірки й production

```sh
npm run lint
npm run build
npm run start
```

## Реалізація

- App Router, TypeScript, CSS Modules, адаптивні світла й темна теми.
- Польські тексти, власні SVG-ілюстрації, шрифти Newsreader і Public Sans.
- Головна використовує SSR для детермінованих умов дня.
- Панель ресурсів використовує React state; перезавантаження скидає значення.
- Код не містить зовнішніх рекламних скриптів, трекерів, iframe чи перенаправлень.
- Заголовки забороняють вбудовування у фрейми та плагінні об’єкти.
